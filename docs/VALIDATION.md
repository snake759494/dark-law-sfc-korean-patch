# 검증

## 확인한 것

헤드리스 snes9x(libretro)로 결과 ROM(SHA-256 `6cf6c38d…`)을 실행해 아래 화면을 확인했습니다.

- 타이틀 화면과 한글 부제, 새로하기/이어하기 메뉴
- 이름 입력 글자판, 능력치 보너스 분배 화면과 도움말
- 오프닝 대사, 숲 속 메시지와 예/아니오 선택지
- 마을 입구·마을 화면, 술집 대사와 메뉴(파티 해산 등)
- 상점 아이템 목록(작은 글꼴)과 구입 예/아니오
- 필드 이동, 문지기 대사
- 첫 동굴 전투: 몬스터 출현, 적 공격, 데미지, 방어, 마법·도구 없음 메시지, 패배 후 여관(숙박하기)

퍼즐과 동굴 문지기는 검증용 치트(메시지 분기 변경, 오브젝트 표 수정)로 넘어갔습니다. 릴리즈 ROM에는 치트가 들어 있지 않습니다.

공개 도구(`tools/build.py`)로 재빌드한 ROM이 릴리즈 ROM과 바이트 단위로 같음을 확인했습니다.

## 확인하지 못한 것

- 전체 시나리오 진행과 엔딩
- 장비를 갖춘 상태의 아군 공격 메시지, 후반 마법·아이템 효과 메시지
- 실기(플래시 카트) 동작
