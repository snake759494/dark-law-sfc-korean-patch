# 기술 설명

## 대사 글꼴

- 원본 대사는 1바이트 코드(00~BF)와 2바이트 코드(FA~FD xx)의 16×16 글꼴을 씁니다. 한글 음절을 사용 빈도순으로 1바이트·2바이트 코드에 배치하고 갈무리14 글리프(15px, 원래 크기)를 그려 넣었습니다(`tools/hfont.py`, `tools/build.py`).
- 대사 문자열은 원래 자리에 다시 쓰고, 넘치는 문자열은 빈 공간으로 옮긴 뒤 포인터를 고쳤습니다(`tools/ptrstr.py`, `tools/rawmod.py`).

## 작은 글꼴 (상점·아이템 목록)

- 상점 목록은 별도의 8×8 글꼴(ROM `0x1624B3`, 2bpp)과 코드→타일 표(`0x25BA5`, 코드당 2바이트: 타일, 탁점 표시)를 씁니다.
- 아이템 이름에 쓰이는 글자를 1바이트 코드에 우선 배치하고, 이 글자들의 갈무리7 글리프를 빈 타일(1~0x8F, 원본 고정 기호 제외)에 그린 뒤 표를 다시 썼습니다. `data/smallmap.json`은 원본 코드→타일 대응입니다.
- 1바이트 칸을 확보하려고 이름 입력 글자판에서 잘 쓰이지 않는 음절 21자를 뺐습니다.

## 예/아니오

- 「はい/いいえ」는 그림 글자 타일이라 맵 기록 루틴 두 곳을 고쳐 「예/아니오」 배치로 바꾸고, 플래그(7F:FFF0)를 세웁니다.
- 필드 NMI(C3:86AC)와 상점 NMI(C2:908B)에 훅을 걸어 플래그가 서 있으면 갈무리14 「예아니오」 타일을 VRAM 5E30/5EB0으로 DMA 전송합니다. 상점 커서 루틴(0x112176)에서도 플래그를 세웁니다(`tools/yesno.py`).

## 기타

- 타이틀 화면 아래에 서울한강체 M으로 그린 「다크 로 - 죽음의 의미」 부제를 넣었습니다(`tools/title.py`).
